# midi-qol (midi-next) type declarations

Generated by `npm run generate:types` from `src/` (tsconfig.types.json). They use fvtt-types, and name some of its
internal types by path (`fvtt-types/src/...`), which fvtt-types' `exports` map doesn't expose. A project using these
declarations adds the same mapping to its tsconfig:

```json
"compilerOptions": {
  "baseUrl": ".",
  "paths": { "fvtt-types/src/*": ["./node_modules/fvtt-types/src/*"] }
}
```
